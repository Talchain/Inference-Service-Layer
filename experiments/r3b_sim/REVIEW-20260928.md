## 1. Executive feedback

1. **Adopt the shared-model direction, but as a *derived compile-time representation inside ISL*, not a new shared schema.** Add a wire field only when a user-visible output consumes it. The binding constraint is missing information, not representation:
   - 101 of the 142 causal links carry no user-unit quantity;
   - 44 of the 67 held levels are model estimates.

   A rich shared schema would mostly encode "unknown".
2. **R3-A's identities and R3-B's dynamics are complementary, and the evidence supports that.**
   - ISL already evaluates declared identities in user units through `execution_frame` (`robustness_analyzer_v2.py:1504-1530`, `_identity_value` at `:2020` @ `14f1a3a`).
   - AIQ reports PRODUCT passing end to end on the served path, and SUM not yet truthful ([#72] 5866834540).
   - "Static graphs are obsolete" is rejected. The real failures are specific and fixable:
     - a normalisation cap read as a ceiling;
     - no `sum` carrier minted;
     - guessed slopes on definitional edges in influence scores;
     - placeholder zeros.
3. **The highest-value next capability: an explained, deadline-aware decision for subscription-type choices.** For each option it gives three boundaries (goal attainment, constraint breach, option preference) over the one or two decisive unknowns, plus the evidence request those boundaries imply. It stays honest when there is no feasible option or no switch.
4. **MVP B is its first dynamic instance, not a second engine.** It needs only:
   - the typed horizon: CEE already holds it but PLoT never forwards it [Repo];
   - stock/flow role with gross/net;
   - onset;
   - a first-passage/terminal rule.

   Everything else routes to the existing static path.
5. **W1 changed as a result of this review's own hypotheses.**
   - **Confirmed:** choosing the comparator on the training fold was anti-conservative on near ties (5.0–8.8% vs a nominal 5%) [Rerun]. The gate now compares against the full-sample best option, which is EVPPI's own baseline: 0–1.0% on those nulls, with no loss of power.
   - **Not confirmed:** clipping.
   - The gate is a **conservative screening test of detectable decision relevance**. It is not an EVPPI estimator and not calibrated.
6. **Keep three EVPPI questions separate:**
   - **scientific eligibility:** whose range is it;
   - **numerical resolution:** floor plus gate;
   - **decision importance:** the magnitude on the user's scale. This is not built yet, and EVPPI's "outcome" unit is the goal's frame, which may not be money at all. For eng-hiring-4 the goal is a calendar date.
7. **Reject:**
   - Report B's GAM-bandwidth diagnosis: ISL fits a fixed-degree polynomial, and our failure was false positives, not collapse to zero;
   - "EVPPI is meaningless under template priors": it is well defined *conditional on Olumi's assumed ranges*, and it should say so, as AIQ has ruled;
   - "constant churn is invalid": treat it as a labelled scenario, to be tested by ablation.
8. **Start at most two external-method prototypes, both offline:**
   - CLD+-style typed compilation of the frozen corpus;
   - scenario discovery (PRIM/RDM) for multi-dimensional decision regions.

   Defer RefineStat-style synthesis, D2D, PyMC and cohort models until a typed target and data exist.

## 3. Proposed architecture and worked examples

### 3.1 Derived compile-time representation (minimum now, with extension points) [Prop]

| Concept | Minimum now (source) | Extension point |
|---|---|---|
| **Quantity** | Value or bounds, unit, `execution_frame` (exists), provenance `source` (exists); **`value_kind`** measurement / estimate / judgement / scenario (derived from source now; a wire field later); explicit `unknown` | Population/segment; units ontology (pp vs %, per month) |
| **Identity** | `nonlinear_identity` product/sum with `stated_in_brief` (exists); evaluated in user units; operand uncertainty via operand spreads | An uncertain relationship is *not* an identity: it becomes a causal response |
| **State and flow** | **`flow_role`** stock / inflow / outflow / rate, target stock, **gross/net**, cadence (new, CEE-local) | Several stocks; cohorts as stock arrays; at-risk populations |
| **Causal response** | `natural_effect` (amount, per-source change, units; exists) with a linear-local form labelled; **onset** (new) | Reference state, valid range, saturation or threshold form, lag and duration |
| **Goal and constraint** | Threshold and direction (exist); **horizon** (in CEE, not forwarded); **evaluation rule**: first passage / terminal / sustained / cumulative (new); constraint cadence | Multiple goals; utility |
| **Decision** | Option interventions (exist); **effective date** (= onset) | Permitted values and combinations; staged or contingent actions |
| **Uncertainty** | Parameter spreads plus **`spread_source`** (W1); named alternative mechanisms kept as separate scenarios, never averaged | Dependence; process variability; ranges without distributions |
| **Qualitative factor** | Unquantified node; taint withholds its dependents | Measurement model |

**Routing** does not choose between dynamic and probabilistic. The two axes are independent:
- **behaviour:** atemporal / dynamic (and later, nonlinear or cohort);
- **uncertainty:** point / range / distribution / alternative mechanisms.

A dynamic model supports both range boundaries and Monte Carlo.

### 3.3 Decision output for the next capability [Prop, using measured numbers]

For each option, and for each decisive unknown over its declared plausible range:

| Boundary | A-180910Z, £59 + feature (X, point values) |
|---|---|
| Goal attainment (first passage by month 12) | Holds while the churn rise per +£10 is ≤ 2.35 pp (net) or ≤ 2.09 pp (gross) |
| Constraint (monthly churn ≤ 4%) | Holds while the churn rise is ≤ 1.5 pp (estimate-based) |
| Preference versus keep-current | £59 is preferred while the churn rise is ≤ 2.53 pp (net) or ≤ 2.79 pp (gross) |
| With the competitive response (−£31,250) | **Infeasible at any rise ≥ 0**, and keep-current is preferred: no switch within range |

**Required result types:**
- feasible throughout;
- infeasible throughout;
- a single switch;
- several switches;
- non-monotone;
- a disconnected region.

An absent or zero threshold is a valid output. **Unweighted scenario fractions are never presented as probabilities.** The evidence request is generated from the boundary nearest to the plausible range, for example: "Could a £10 rise lift monthly churn by more than 1.5 points?"

**Next extensions, in priority order:**
1. 2-D regions: churn response × competitive response, and churn response × gross acquisition.
2. Onset and lag as a boundary dimension (release month).
3. Robust option search over combinations (price × feature timing), using regret under declared ranges.
4. A trade-off frontier (goal attainment vs limit headroom).
5. Staged decisions, e.g. "raise the price if month-3 churn is below X". This needs an observation model.

**New inputs needed:** the objective (revenue vs P(goal) vs utility are not interchangeable), plausible ranges, and onset dates.

Served runs default to **10,000** draws (`STANDARD_N_SAMPLES_DEFAULT`, PLoT `src/config/sampling.ts:40`), and `factor_evppi` uses the full retained sample. The n=500 power loss therefore mostly lies off the served path.

**Answers to the review's hypotheses [Rerun]:**
- **Comparator from the training fold:** *confirmed*. Gate alone: 5.0–8.8% false rejections on tie and near-tie nulls. **Fixed:** the full-sample best option, 0–1.0%. The row fails the old comparator (5/200 > 2).
- **Pooled SE across dependent folds:** empirically *conservative*, not calibrated at 5%. The wording must say "screening test".
- **Clipping:** *not confirmed* (weak tail 12→10, 26→25 without clipping).
- **Degree and repeated splits:** modest, mixed effects. A single seeded split keeps AIQ's "same request, same status" condition.
- **Estimand:**
  - The gate measures the held-out value of a rule *learned from half the draws*: detectable decision relevance.
  - EVPPI measures the value of perfect information.
  - The gate is a necessary-evidence screen, never a replacement estimate.

**AIQ's control (eng-hiring-4)** [Rerun, offline replay]: AIQ's CEE→PLoT request was run through a local PLoT `ccd602c` and local ISL builds.
- The base reproduces the served row exactly: 0.000261 > floor 0.000171, `resolved`.
- The head gives `below_resolution` / `decision_gain_not_significant`, with values unchanged.
- The held-out gain is 0.000085 ± 0.000216 (z = 0.39).
- **So the "gather evidence" control row in AIQ 5866850180 flips.** AIQ must re-base it.

**Remaining evidence gaps** (a separately versioned follow-on study, proposed and not started):
- the family-wise rate across the factors tested in one run;
- correlated inputs;
- grouped or joint information, where individual factors carry zero value but the joint does. A per-factor gate cannot see this; neither can per-factor EVPPI;
- matched-cost alternatives: incremental-benefit regression for 2 options, a GP-based EVPPI, and analytic or converged nested references;
- metrics: false-positive rate with confidence intervals, power, EVPPI bias and RMSE against the reference, and decision regret.

**User-facing meaning (the owner decision):** "resolved" now means *detectably decision-relevant under the model's assumed ranges*.
- **Scientific eligibility** is `spread_source`: user vs template. Template-only priors are **not** repaired by precision.
- **Numerical resolution** is floor plus gate. A failure there is *not* proof that the information has no value.
- **Decision importance** is undefined. EVPPI is in goal-frame units, abstract for eng-hiring-4's date goal, so it is not money and not "worth spending".
